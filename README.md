# SPHEREx Zodi
Build a purely empirical model of the zodiacal light from *SPHEREx* data.

## Authors:
- **David W. Hogg** (NYU) (Flatiron)
- **Andrew Saydjari** (Princeton)

## Projects:
- Construct invariant scalar functions of vectors for contributions to the *SPHEREx* intensity maps.
- Use functional differences to component separate the zodi from scattered light and the astronomical sky.
- Interrogate residuals to discover time variabilities and dynamical effects of the planets.
